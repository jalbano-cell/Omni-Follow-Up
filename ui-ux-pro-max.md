# UI/UX Pro Max — Design System Reference

> OmniGrid Digital · Premium Interface Standards

---

## Design Philosophy

Every interface decision must serve one of three goals:
1. **Clarity** — the user instantly understands what to do
2. **Trust** — the interface feels credible and premium
3. **Momentum** — the user moves forward without friction

## Component Checklist

Before shipping any component, verify:

- [ ] Hover state defined
- [ ] Focus ring visible (keyboard accessible)
- [ ] Active / pressed state
- [ ] Disabled state
- [ ] Loading / skeleton state
- [ ] Empty state
- [ ] Error state
- [ ] Mobile touch target ≥ 44×44px
- [ ] Color contrast ≥ 4.5:1 (WCAG AA)
- [ ] Motion respects `prefers-reduced-motion`
- [ ] Dark mode variant (if applicable)

## Animation Principles

| Principle | Value |
|-----------|-------|
| Duration (micro) | 80–120ms |
| Duration (element) | 150–250ms |
| Duration (page) | 300–400ms |
| Easing default | `cubic-bezier(0.16, 1, 0.3, 1)` |
| Easing enter | `ease-out` |
| Easing exit | `ease-in` |
| Stagger delay | 30–60ms per child |

Use animation for:
- **State transitions** (hover, active, focus)
- **Content reveal** (scroll-triggered fade/slide)
- **Loading feedback** (skeleton pulse, spinner)
- **Success/error moments** (checkmark, shake)

Never animate for decoration alone.

## Quality Bar

Before any interface is considered complete, ask:

1. Does this look like a premium agency designed it?
2. Would this impress a paying client?
3. Does it stand beside Linear, Stripe, Vercel, or Framer?
4. Does it feel handcrafted rather than generated?

If the answer to any of these is **no** — keep refining.
